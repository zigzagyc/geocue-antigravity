# Science Fair Abstract: GeoCue

Here are four variations of the abstract. The new **Option 4** specifically highlights the novel AI-assisted "vibe coding" development process, while the others now include a mention of this methodology.

## Option 1: Technical Focus (Computer Science & Engineering)
**Title:** GeoCue: Enhancing Spatial Annotation through Multimodal Generative AI

**Abstract:**
Traditional location-based services (LBS) primarily rely on static text and star ratings to crowd-source information about the physical world. This project introduces GeoCue, a cross-platform mobile application that enables "audio tagging"—allowing users to anchor voice recordings to specific geographic coordinates. The application was developed using a novel **"Agentic Workflow,"** leveraging the **Antigravity** AI coding assistant to accelerate the implementation of complex features through high-level intent, often referred to as **"vibe coding."** Technologically, the app utilizes the Flutter framework and Google Maps SDK, integrating Google's Gemini 1.5 Flash model to process audio cues. The system utilizes multimodal Generative AI to automatically transcribe spoken content and perform on-the-fly translation. This project demonstrates not only the practical application of Generative AI in spatial computing but also the efficiency of next-generation AI-assisted software development life cycles.

## Option 2: Accessibility & Interaction Focus (HCI)
**Title:** GeoCue: A Novel Interface for Multilingual, Voice-First Location Tagging

**Abstract:**
As digital interfaces increasingly overlay the physical world, there is a need for more natural and accessible ways to interact with our surroundings. GeoCue is a research prototype that explores the use of voice as the primary medium for location tagging, built using an **AI-first "vibe coding" methodology** where the **Antigravity agent** handled implementation details based on high-level user goals. This approach allowed for rapid prototyping of complex accessibility features. Unlike conventional map apps, GeoCue allows users to record rapid on-site audio notes, utilizing the Gemini Generative AI model to facilitate immediate speech-to-text conversion and language translation. The results indicate that merging geolocation with AI-powered audio processing—developed through human-AI collaboration—provides a faster, more expressive method for capturing location data while ensuring the content remains structured, searchable, and inclusive.

## Option 3: Concise (Standard High School Science Fair)
**Title:** GeoCue: Location-Based Audio Anchoring with AI Transcription

**Objectives:** To develop a mobile application that bridges the gap between physical locations and digital information using audio, while evaluating the efficacy of **AI-agentic coding (Antigravity)** in accelerating complex software development.

**Methods:** The application, "GeoCue," was built using Flutter for cross-platform capability. The development process utilized **Antigravity**, an advanced AI agent, to implement features via natural language prompts ("vibe coding"). We integrated Google's multimodal Gemini AI to process uploaded audio files for transcription and translation.

**Results:** A fully functional prototype was created where users can record, upload, and playback audio anchored to specific coordinates. The use of the Antigravity agent significantly reduced development time for complex integrations like Firebase and Google Maps.

**Conclusions:** GeoCue validates the feasibility of a voice-first, AI-enhanced mapping platform. Furthermore, it demonstrates that **AI-agentic workflows** can empower developers to build sophisticated, full-stack applications by focusing on high-level design and functionality rather than boilerplate code.

## Option 4: The Future of Development (AI-Agentic & Vibe Coding Focus)
**Title:** Building GeoCue: A Case Study in Agentic AI and "Vibe Coding" for Rapid App Development

**Abstract:**
The landscape of software engineering is shifting from manual coding to AI-assisted intent realization. This project, GeoCue, serves as a dual investigation: 1) creating a functional multimodal location-tagging application, and 2) evaluating the efficacy of **"Antigravity,"** an advanced AI coding agent, in a **"vibe coding"** workflow. By defining high-level system behaviors and architectural goals (the "vibe") rather than writing every line of code manually, the developer collaborated with the AI to handle end-to-end implementation tasks—from setting up Firebase backend services to integrating the Gemini 1.5 Flash model for audio transcription. The result is a production-grade Flutter application built in a fraction of standard development time. This project highlights the potential of Agentic AI to lower the barrier to entry for complex software engineering and shift the human role from coder to system architect.
